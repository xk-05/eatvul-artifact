# Limitations for Reviewers

## Evidence boundary

The released observation is a serialized AST-token sequence plus target-model
outputs. It supports sample-level screening and review routing. It does not
provide source locations, corrected labels, compilation, semantic equivalence,
or security/functional validation.

## Missing objects

The public artifact does not include true inserted spans, source diffs,
source-to-token mappings, CFGs, PDGs, compiler-validated adaptive snippets, or
complete paired prediction logs for every historical layer. Fixed token
deletion is therefore a diagnostic detector-output sensitivity analysis, not a
source repair evaluation.

## Data availability

Raw AST-token splits and `Code and Dataset.zip` are excluded because
redistribution authorization has not been established. Public derived evidence,
sample-budget rows, hashes, and run metadata are included. An historical backup
is incomplete because part `.010` is missing; this does not invalidate the
verified final derived evidence bundle, but prevents reconstruction of every
historical raw output from that backup alone.

## Model coverage and operating points

The CodeBERT rows are a bounded feasibility check under a 256-token prefix, not
the main efficacy evidence. Realized unattacked-review rates differ from nominal
calibration budgets across targets, so results should be interpreted with their
observed review loads rather than as a universal threshold guarantee.

## Reproduction limits

Tables 2--9 and the confidence summaries can be audited from public files. Full
model retraining requires authorized raw splits. Vector PDFs regenerated by
different Matplotlib versions may have different bytes or metadata; compare
their rendered content and underlying CSV values.
